# meta-rowanos-framework

Open and source-releasable Yocto integration layer for the RowanOS platform.

This layer is reserved for Qt 6, KDE Frameworks, Kirigami, Plasma, FEX,
Proton/Wine, DXVK, VKD3D-Proton, PPSSPP, graphics, multimedia, and other
open-source system foundations. Patches to GPL or LGPL components belong here
or in the applicable upstream BSP fork.

The layer must not depend on meta-rowanos-device.
